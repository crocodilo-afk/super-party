# Super Party

Programa de chamada de voz, chat e compartilhamento de tela entre amigos.
A voz e a imagem vão **direto de um PC para o outro** (WebRTC) — não tem servidor no meio e nada é gravado.

Esta pasta guarda a **página do aplicativo**. O programa instalado procura aqui a versão nova toda vez que abre.

- `index.html` — o aplicativo inteiro (uma página só)
- `peerjs.min.js` — a biblioteca que apresenta as pessoas pelo código da sala
